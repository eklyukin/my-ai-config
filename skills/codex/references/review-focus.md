# Codex Review Focus Areas

These are the criteria that Codex CLI evaluates when reviewing code changes.

## Code Quality
- Clean code principles
- Naming conventions (consistent, descriptive)
- Code organization and structure
- DRY violations and unnecessary duplication

## Architecture
- Design patterns (appropriate usage)
- Separation of concerns
- Component boundaries
- Dependency management

## Best Practices
- Language-specific idioms
- Framework conventions
- Error handling patterns
- Resource management (cleanup, disposal)

## Security
- Input validation at trust boundaries
- Authentication / authorization checks
- Data sanitization
- Common vulnerability patterns (OWASP top 10)

## Performance
- Algorithm efficiency
- Resource usage (memory, CPU)
- Optimization opportunities
- Unnecessary allocations or computations

## Maintainability
- Documentation (where non-obvious)
- Test coverage
- Code complexity (cyclomatic, cognitive)
- Technical debt indicators
